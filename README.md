# Super Multi-functional Integrated Software

> 一个集成式多功能工具软件 —— 把日常高频使用的实用工具整合到一个统一的界面中，免去在多个软件之间来回切换的麻烦。

## 📖 项目简介

**Super Multi-functional Integrated Software** 是一个面向日常效率场景的**集成式工具箱**。

日常工作和学习中，我们往往需要同时安装大量零散的小工具：格式转换、文本处理、编码解码、系统信息查看、批量重命名……它们界面风格各异、安装包零散、还常常夹带广告。本项目希望用**一个统一的入口**来解决这个问题：把常用的多功能模块集中到一个软件里，风格统一、离线可用、启动即用。

---

## ✨ 核心特性

| 特性 | 说明 |
| --- | --- |
| 🧩 **模块化集成** | 各功能以独立模块组织，可按需启用，互不干扰 |
| 🖥️ **统一界面** | 所有工具共用一套 UI 风格与交互逻辑，学习成本低 |
| ⚡ **轻量高效** | 启动迅速、资源占用低，不驻留后台 |
| 🔌 **离线可用** | 核心功能全部本地执行，无需联网 |
| 🌐 **中文优先** | 界面与文档以简体中文为主 |
| 🧱 **易于扩展** | 清晰的模块接口约定，便于新增功能 |

> ⚠️ 具体功能模块清单将随开发进度持续更新，详见下方 [功能模块规划](#-功能模块规划)。

## 🗂️ 功能模块规划

当前处于**早期开发阶段**，以下模块为规划方向，实际以发布版本为准：

- [ ] **文本工具** —— 大小写转换、去重、正则替换、行排序、字符统计
- [ ] **编码转换** —— Base64 / URL / Hex / Unicode 编解码
- [ ] **格式转换** —— 常见文档与图片格式互转
- [ ] **系统信息** —— 硬件概览、进程查看、磁盘占用分析
- [ ] **批量处理** —— 文件批量重命名、批量替换、批量压缩
- [ ] **开发辅助** —— JSON 格式化、时间戳转换、UUID 生成、哈希计算

## 🤝 参与贡献

欢迎通过以下方式参与：

1. **提交 Issue** —— 反馈问题或提出功能建议
2. **提交 Pull Request** —— 修复缺陷或实现新功能
3. **完善文档** —— 修正错别字、补充说明

### 贡献流程

```bash
# 1. Fork 本仓库

# 2. 创建特性分支
git checkout -b feature/your-feature

# 3. 提交改动
git commit -m "feat: 添加某功能"

# 4. 推送分支
git push origin feature/your-feature

# 5. 提交 Pull Request
```

### 提交信息规范

建议遵循 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/)：

| 前缀 | 含义 |
| --- | --- |
| `feat` | 新增功能 |
| `fix` | 修复缺陷 |
| `docs` | 文档变更 |
| `refactor` | 重构 |
| `style` | 格式调整 |
| `chore` | 构建 / 工具链变更 |
